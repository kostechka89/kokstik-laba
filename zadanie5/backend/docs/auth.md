# Ролевая модель

- `reader` — базовый пользователь, может читать новости и оставлять комментарии.
- `author` — верифицированный пользователь (`is_verified_author=true`), может создавать новости.
- `admin` — администратор (`is_admin=true`), может редактировать/удалять любые новости и комментарии.

Проверка прав выполняется через зависимости FastAPI в `app/api/deps.py`.
